  VEGAS — FEATURE ROADMAP (P1-P5)
══════════════════════════════════════════════════════════════

P1 ─ Pipeline Cache Pre-Seeding  [High Gain / Low Effort]
───────────────────────────────────────────────────────────
  Problem: Every game launch compiles shaders from scratch,
  causing stutter for the first few minutes.
  
  Fix: Save the Vulkan pipeline cache after first session,
  reload on next launch. Even better: ship known-good caches
  for popular titles (Tomb Raider 2013, Prey).
  
  Gain: Eliminates re-compile stutter on 2nd+ launch.

P2 ─ Adaptive Quality Scaling  [High Gain / Medium Effort]
───────────────────────────────────────────────────────────
  Problem: When GPU overheats or frame times spike, there's
  no automatic fallback. User must manually lower settings.
  
  Fix: When analyzePerformance() detects Overheating or
  Stuttering state, dynamically:
    • Lower shadow map resolution via D3D state overrides
    • Force lower mip LOD bias (blurrier textures further away)
    • Reduce draw distance hints
  All reversible when performance recovers.
  
  Gain: Prevents thermal throttling, keeps FPS stable.

P3 ─ Dynamic Rendering (VK_KHR_dynamic_rendering)  [Medium Gain / Medium Effort]
───────────────────────────────────────────────────────────────────────────────
  Problem: DXVK creates VkRenderPass + VkFramebuffer objects
  for every draw call, burning CPU time.
  
  Fix: Use vkCmdBeginRendering instead. Already well-tested
  in upstream DXVK 2.4+.
  
  Gain: 5-10% CPU reduction on draw call path.

P4 ─ Memory Pressure Handling  [Medium Gain / Low Effort]
──────────────────────────────────────────────────────────
  Problem: Adreno 610 only has 3-4 GB shared RAM. High-res
  textures can fill VRAM and cause OOM crashes.
  
  Fix: When VRAM is near full:
    • Fall back to host-visible memory for low-priority resources
    • Aggressively free unused image views
    • Lower the VRAM cap in applyVramSwap()
  
  Gain: Prevents out-of-memory crashes at high-res textures.

P5 ─ Descriptor Pool Recycling  [Low Gain / Low Effort]
────────────────────────────────────────────────────────
  Problem: Descriptor pools are created/destroyed per frame,
  causing heap churn.
  
  Fix: Pre-allocate descriptor pools per tier. Reuse pools
  across frames with VK_DESCRIPTOR_POOL_CREATE_FREE_DESCRIPTOR_SET_BIT.
  
  Gain: 2-5% CPU reduction, less memory churn.

──────────────────────────────────────────────────────────

DEFERRED (for later):

P6 ─ TBDR Tile-Aware Draw Sorting  [Highest Gain / High Effort]
  Sort draws by shader program + depth range so Adreno's tile
  buffer doesn't spill to system RAM. 15-40% gain on overdraw-
  heavy scenes (foliage, particles). Needs careful state tracking
  to avoid breaking D3D9 assumptions.
